## 4. 任务 8 输入结论

基于本次逐牌核查，任务 8 不应该再按旧文档把所有牌混在一起修，而应按下面顺序推进：

1. 先修 `1007 / 1022 / 1025 / 1035 / 1044 / 1063` 这类对玩家理解偏差最大、且实际语义错误最明显的问题。
2. 再收口 `1026 / 1041 / 1045 / 1054 / 1064` 这类“玩法链路已存在，但条件或表现不完整”的问题。
3. `1013 / 1021 / 1033 / 1036` 当前已经有明确消费链路，不应继续作为“任务 7 未核清”的阻塞项。
