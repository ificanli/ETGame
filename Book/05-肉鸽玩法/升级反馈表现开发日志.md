## 决策记录

### 2026-04-21 - 升级弹字挂在 `MainPanel`，不新开独立 Panel
- **背景**：用户要求使用 YIUI，但升级弹字本质是短时覆盖反馈，不是独立页面。
- **方案**：在 `MainPanel` 的 YIUI 根节点下动态创建局部 `LevelUpToastRoot/LevelUpToastView`，只把一次性文字节点和动画放在运行时。
- **原因**：符合 `yiui-unity-mcp` 对“临时覆盖交互/少量简单节点”的允许边界，同时避免手改 `YIUIGen` 和额外 prefab 生成链。
- **替代方案**：新建独立 `Common` prefab；放弃原因是当前终端环境下无法直接跑 Unity 生成链，手搓完整 YIUI prefab 风险更高。

### 2026-04-21 - 弹字动画使用 `DOTween`
- **背景**：升级弹字需要同时做放大、上浮和淡出。
- **方案**：使用仓库已接入的 `DG.Tweening`，对 `RectTransform` 和 `CanvasGroup` 直接做序列动画。
- **原因**：实现短、行为稳定，且支持重复升级时通过 `Kill` 干净重播。
- **替代方案**：参考 `CombatTextComponent` 手写 `LateUpdate`；放弃原因是这类单节点 UI 动画没有必要再维护一套自定义时间轴。

## 问题日志

### 2026-04-21 - 首轮编译失败
- **现象**：`CanvasGroup.DOFade` / `RectTransform.DOAnchorPos` 在当前程序集下不可用，`ResourcesLoaderComponent` 也触发了 ET `await` 后 Entity 访问分析器报错。
- **处理**：把 UI 动画改成 `DOTween.To(...)`，并对 `ResourcesLoaderComponent` 增加 `EntityRef` 重取。
- **结果**：重新执行 `dotnet build ET.sln` 后整仓通过，0 warning / 0 error。
