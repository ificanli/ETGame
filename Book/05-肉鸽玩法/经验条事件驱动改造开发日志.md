## 决策记录

### 2026-04-11 - 经验条改为统一事件驱动，不改经验规则
- **背景**：当前问题在于 UI 刷新方式是每帧轮询，不在于经验或升级规则本身。
- **方案**：新增客户端 `EventRogueProgressChanged`，由同步消息和运行时重置统一触发，`MainPanel` 和 `HPView` 订阅后刷新。
- **原因**：可以最小代价收口两个轮询口，同时不改服务端逻辑和网络协议。
- **替代方案**：只改 `MainPanel`，保留 `HPView` 轮询；放弃原因是会遗留第二个经验条轮询入口。

### 2026-04-11 - 保留非玩家单位显示等级轮询，只收口玩家自己的肉鸽进度
- **背景**：`HPView` 不只显示玩家经验条，还承担怪物/其他单位头顶等级文本刷新。
- **方案**：玩家自己的等级/经验改为事件驱动，`LateUpdate()` 仅保留非玩家单位的显示等级刷新。
- **原因**：`UnitDisplayLevelComponent` 的变更来自 `cn.etetet.map`，本次不跨包重构这条链路，先以最小风险实现任务目标。
- **替代方案**：把所有 `HPView` 等级刷新都改为事件驱动；放弃原因是会引入跨包事件边界和额外联调面。

## 问题日志

### 2026-04-11 - 清理 `Logs` 目录时存在 Unity 工作进程占用
- **现象**：执行定向测试前尝试删除 `Logs` 目录，`AssetImportWorker*.log` 与 `shadercompiler*.log` 被其他进程占用，无法彻底清空。
- **原因**：本地 Unity 相关后台进程仍持有部分日志文件句柄。
- **解决**：不中断本轮验证，继续执行定向测试；测试命令本身成功，后续如需严格清空日志再单独处理占用进程。
