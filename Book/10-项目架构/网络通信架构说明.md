# 网络通信架构说明

**创建时间**：2026-04-10
**最后更新**：2026-04-10

## 1. 服务进程拓扑

```
┌─────────────────────────────────────────────────────────────────────┐
│                        Zone 1（基础设施）                             │
│                                                                     │
│  ┌──────────────────┐    ┌─────────────────────────────────────┐   │
│  │ ServiceDiscovery │    │ Router01 / 02 / 03 / 04            │   │
│  │ （服务注册与发现）  │    │ （客户端接入负载均衡）                  │   │
│  └──────────────────┘    └─────────────────────────────────────┘   │
│                                                                     │
│  ┌──────────────────┐                                               │
│  │ RouterManager    │                                               │
│  │ （管理 Router 实例）│                                               │
│  └──────────────────┘                                               │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│                        Zone 2（游戏服务）                             │
│                                                                     │
│  ┌────────┐  ┌──────────┐  ┌──────────┐  ┌──────────────────────┐ │
│  │ Realm  │  │ Gate(×N) │  │ Location │  │ MapManager           │ │
│  │ 认证入口 │  │ 连接网关   │  │ Actor寻址 │  │ 地图实例分配            │ │
│  └────────┘  └──────────┘  └──────────┘  └──────────────────────┘ │
│                                                                     │
│  ┌────────┐  ┌──────────────────────────────────────────────────┐  │
│  │ Match  │  │ Map (×N)                                        │  │
│  │ 匹配服务 │  │ 战斗地图实例（每局独立 Fiber）                      │  │
│  └────────┘  └──────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

| 服务 | 职责 | 备注 |
|------|------|------|
| **ServiceDiscovery** | 服务注册、心跳检测、拓扑发现 | 每个 Fiber 持有 ServiceDiscoveryProxy 缓存 |
| **Router** | 客户端 TCP 接入、负载均衡 | 4 个实例轮询 |
| **Realm** | 账号认证，分配 Gate 地址 | 无状态 |
| **Gate** | 维持客户端 Session，消息转发 | 每个玩家一个 Player Entity |
| **Location** | Actor 地址映射（Id → ActorId） | 支持 Lock/Unlock 保证转移安全 |
| **MapManager** | 分配/回收 Map 实例 | 按需创建 |
| **Match** | 匹配队列、组队 | 匹配成功后通知 Gate 进入地图 |
| **Map** | 战斗逻辑、AOI、单位管理 | 每局独立 Fiber |

## 2. 客户端连接流程

### 阶段 1：认证（Realm）

```
Client                     Router              Realm
  │                          │                    │
  ├──── TCP Connect ────────>│                    │
  │                          │                    │
  ├──── C2R_Login ──────────────────────────────>│
  │     (Account, Password)                       │
  │                                               │
  │                              [ServiceDiscovery│
  │                               查询可用 Gate]    │
  │                                               │
  │<──── R2C_Login ──────────────────────────────┤
  │     (GateAddress, Key, GateId)                │
```

### 阶段 2：登录 Gate

```
Client                     Router              Gate              Location
  │                          │                   │                   │
  ├──── TCP Connect ────────>│                   │                   │
  │                          │                   │                   │
  ├──── C2G_LoginGate ─────────────────────────>│                   │
  │     (Key, GateId)                            │                   │
  │                                         [验证 Key]              │
  │                                              │                   │
  │                                         [创建 Player]           │
  │                                              │                   │
  │                                              ├── Register ─────>│
  │                                              │   (PlayerId→ActorId)
  │<──── G2C_LoginGate ────────────────────────┤                   │
  │     (PlayerId)                               │                   │
```

### 阶段 3：进入地图

```
Client          Gate           GateMap          MapManager         Map            Location
  │               │               │                │                │                │
  ├─ C2G_EnterMap>│               │                │                │                │
  │               │               │                │                │                │
  │               ├─ Create ─────>│                │                │                │
  │               │          [创建临时 Unit]        │                │                │
  │               │               │                │                │                │
  │<─ G2C_EnterMap┤               │                │                │                │
  │  (MyId)       │               │                │                │                │
  │               │               │                │                │                │
  │               │          [TransferHelper.TransferLock]          │                │
  │               │               │                │                │                │
  │               │               ├─ GetMapRequest────────────────>│                │
  │               │               │                │          [分配 Map 实例]        │
  │               │               │<─ MapActorId ──┤                │                │
  │               │               │                │                │                │
  │               │               ├─ Lock ─────────────────────────────────────────>│
  │               │               │                │                │                │
  │               │               ├─ M2M_UnitTransferRequest ─────>│                │
  │               │               │   (序列化 Unit + Components)    │                │
  │               │               │                │           [反序列化创建 Unit]    │
  │               │               │<─ NewActorId ──────────────────┤                │
  │               │               │                │                │                │
  │               │               ├─ Unlock ───────────────────────────────────────>│
  │               │               │                │                │     (更新 ActorId)
  │               │          [销毁 GateMap Unit]   │                │                │
  │               │               │                │           [Unit 激活在 Map 上]  │
```

```
Client              Gate               Match             MapManager          Map
  │                   │                  │                   │                 │

  │                   │             [匹配成功]                │                 │

  │                   │                  │<─ MapActorId ─────┤                 │

  │                   │                  │                   │                 │

```

## 3. 消息类型体系

### 接口继承关系

```
IMessage（基类，无需响应）
├── ISessionMessage（Session 上的任意消息）
│   └── ISessionRequest → ISessionResponse（Session RPC）
├── ILocationMessage（经 Location 路由的单向消息）
│   └── ILocationRequest → ILocationResponse（Location RPC）
└── IRequest → IResponse（通用 RPC）
```

### 消息路由模式

| 前缀 | 方向 | 接口 | 说明 |
|------|------|------|------|
| `C2R_` | Client → Realm | ISessionRequest | 认证 |
| `C2G_` | Client → Gate | ISessionRequest | 登录、匹配、确认起装 |
| `G2C_` | Gate → Client | ISessionMessage | Gate 推送 |
| `C2M_` | Client → Map | ILocationRequest | 游戏操作（移动、射击、交互） |
| `M2C_` | Map → Client | IMessage | 广播（状态同步、战斗事件） |
| `M2M_` | Map → Map | IRequest | 跨地图转移 |
| `G2Match_` | Gate → Match | IRequest | 匹配请求 |
| `Match2Map_` | Match → Map | IRequest | 初始化对战副本 |
| `A2Map_` | Any → Map | IRequest | 服务间内部通信 |

### Opcode 分配

| 包 | 范围 | 说明 |
|----|------|------|
| Login | 10000-10099 | 登录认证 |
| StateSync | 10700-10799 | 战斗同步 |
| Item | 10800-10899 | 物品背包 |
| Map | 11000-11099 | 地图交互 |
| Equipment | 11100-11199 | 起装装备 |
| Match | 11300-11399 | 匹配系统 |
| Archive | 12020-12099 | 存档系统 |

## 4. Actor 寻址模型

### Location Service

Location 是整个分布式架构的核心——它维护 `EntityId → ActorId` 的映射，使得消息发送方无需知道目标 Entity 当前在哪个 Map 实例上。

```
┌──────────────────────────────────────────────────────┐
│ Location Service                                     │
│                                                      │
│  LocationOneType                                     │
│  ├── locations: { PlayerId → ActorId }               │
│  │       例: { 10001 → Gate3.Player.ActorId }         │
│  │       例: { 10001 → Map5.Unit.ActorId }            │
│  ├── lockInfos: { PlayerId → LockInfo }              │
│  │       转移期间锁定，新消息排队等待                     │
│  └── requestQueue: 锁定期间的请求队列                   │
└──────────────────────────────────────────────────────┘
```

### 消息发送流程

```csharp
// 通过 ActorLocationSender 自动查询 Location 并缓存
ActorLocationSender sender = scene
    .GetComponent<ActorLocationSenderComponent>()
    .Get(targetUnitId);
await sender.Call(request);  // 自动：查 Location → 获取 ActorId → 发送
```

### 转移安全（Lock/Unlock）

```
1. TransferHelper.TransferLock(unit)
   ├── Location.Lock(unitId)       ← 锁定，新消息排队
   ├── 序列化 Unit + Components
   ├── M2M_UnitTransferRequest     ← 发送到目标 Map
   ├── 目标 Map 反序列化创建 Unit
   ├── Location.Unlock(unitId, newActorId)  ← 解锁，更新地址
   └── 排队消息按新地址转发
```

## 5. 广播机制（AOI）

### 服务端广播

```csharp
MapMessageHelper.NoticeClient(unit, message, NoticeType.Broadcast);
```

**NoticeType**：

| 类型 | 说明 |
|------|------|
| `NoNotice` | 不发送 |
| `Self` | 仅发给自己 |
| `Broadcast` | 发给所有 AOI 可见玩家 |
| `BroadcastWithoutSelf` | 发给自己以外的可见玩家 |

### 广播流程

```
unit.GetBeSeePlayers()
  → Dictionary<long, EntityRef<AOIEntity>>（AOI 范围内观察者）
    → 对每个观察者：
      → UnitGateInfoComponent.ActorId（获取 Gate 上的 Player ActorId）
      → MessageSender.Send(actorId, message)
        → Gate 转发给客户端 Session
```

**额外可见性**：`ExtraUnitVisibilityComponent` 处理迷雾/隐匿等特殊可见性规则。
