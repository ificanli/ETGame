# 局外起装 UI 制作绑定清单

## 1. 文档用途
- 给 UI 制作直接使用。
- 给后续界面绑定直接对照协议和配置字段。
- 不替代需求文档，本清单只关心“界面上要有什么、怎么绑”。

## 2. 本期页面

### 2.1 起装主界面
职责：
- 展示当前正式携带态。
- 展示仓库。
- 展示当前财富。
- 支持仓库与正式携带态之间的即时拖拽。
- 支持一键卸下。
- 支持点击进入“背包配置界面”。
- 支持点击“起装完成”。

必须有的区域：
- 英雄信息区域
- 固定槽位区域
- 当前背包区域
- 当前安全格区域
- 仓库区域
- 财富区域
- 操作按钮区域

### 2.2 背包配置界面
职责：
- 只处理商店待购买草稿。
- 只展示背包、安全格、商店分类、商店列表、当前草稿价格。
- 不做仓库拖拽。

必须有的区域：
- 商店分类页签
- 商店物品列表
- 物品详情预览
- 草稿背包区域
- 草稿安全格区域
- 草稿总价区域
- “清空草稿”按钮
- “确认返回”或关闭按钮

### 2.3 通用弹窗
至少需要：
- 一键卸下确认弹窗
- 起装失败提示弹窗或 toast
- 放置失败提示 toast

## 3. 起装主界面节点清单

### 3.1 固定槽位
固定 4 个：
- 枪械1槽
- 枪械2槽
- 护甲槽
- 背包槽

每个槽位需要：
- 空状态底图
- 物品图标
- 品质框
- 名称文本
- 尺寸文本
- 空状态标签
- 可点击区域

推荐绑定字段：
- `ConfigId`
- `Icon`
- `Quality`
- `GridWidth`
- `GridHeight`
- `IsEmpty`
- `IsDraft`
- `CanDrop`

### 3.2 当前背包区域
需要：
- 网格根节点
- 格子模板
- 物品模板
- 拖拽预览层
- 合法落点高亮层
- 非法落点高亮层

每个格子需要状态：
- 默认
- 可放置
- 被占用
- 非法

每个物品卡片需要：
- 图标
- 品质框
- 尺寸占格
- 堆叠数量
- 草稿角标
- 价格角标

### 3.3 当前安全格区域
表现与背包区域一致，但要额外有：
- 安全格标题
- 安全格专属边框/底色
- “死亡保留”提示文案

### 3.4 仓库区域
本期建议做成列表或分页宫格，不需要二维仓库。

每个仓库条目需要：
- 图标
- 名称
- 数量
- 品质框
- 尺寸
- 可拖拽区域

### 3.5 财富与按钮区
至少需要：
- 当前财富文本
- 财富图标
- 商店入口按钮
- 配置背包按钮
- 起装完成按钮
- 一键卸下按钮
- 当前确认状态文本

## 4. 背包配置界面节点清单

### 4.1 商店分类
分类建议按配置 `LoadoutShopCategory`：
- `1` 武器
- `2` 护甲
- `3` 背包
- `4` 消耗品
- `5` 杂项

每个分类按钮需要：
- 默认态
- 选中态
- 未解锁/空列表态

### 4.2 商店物品列表
每个商店条目需要：
- 图标
- 名称
- 价格
- 品质框
- 尺寸
- 背包容量标签
- 点击购买/放入按钮

如果是背包条目，额外显示：
- `BackpackWidth x BackpackHeight`

如果是固定槽装备，额外显示：
- 可放槽位标签

### 4.3 详情预览
建议展示：
- 大图标
- 名称
- 价格
- 品质
- 尺寸
- 背包容量
- 简短描述
- 当前是否已放入草稿

## 5. 通用组件

### 5.1 物品卡片组件
统一用于：
- 固定槽位中的物品
- 背包物品
- 安全格物品
- 仓库条目
- 商店条目

建议统一支持：
- 图标
- 品质框
- 名称
- 数量
- 尺寸
- 价格
- 草稿角标
- 选中态
- 禁用态

### 5.2 网格格子组件
统一用于：
- 背包格子
- 安全格格子

建议支持：
- 默认态
- 可放置态
- 不可放置态
- 被正式物品占用态
- 被草稿物品占用态

### 5.3 拖拽幽灵组件
拖拽时建议有：
- 半透明物品图
- 跟随鼠标
- 占格预览
- 合法绿色描边
- 非法红色描边

## 6. 交互反馈

### 6.1 主界面即时操作
- 仓库拖到固定槽位/背包/安全格：立即发协议。
- 当前携带态拖回仓库：立即发协议。
- 当前携带态内部移动：立即发协议。
- 成功后等待 `G2C_LoadoutStateChanged` 刷新正式状态。

### 6.2 商店草稿操作
- 商店条目点击后进入草稿预览，不立即扣钱。
- 草稿只能放到正式空位。
- 若目标被正式物品占用，直接提示。
- 草稿只在本地显示角标，不混进正式状态样式。

### 6.3 按钮反馈
- 一键卸下：必须二次确认。
- 起装完成成功：提示“起装完成，可进局”。
- 起装完成失败：提示“财富不足”或具体失败原因。

## 7. 绑定数据来源

### 7.1 协议
初始化快照：
- `G2C_GetHeroList`

正式状态变化推送：
- `G2C_LoadoutStateChanged`

即时操作请求：
- `C2G_LoadoutTakeFromWarehouse`
- `C2G_LoadoutPutToWarehouse`
- `C2G_LoadoutMoveOwnedItem`
- `C2G_LoadoutOneKeyUnload`

确认起装请求：
- `C2G_ConfirmLoadout`

### 7.2 配置
主配置表：
- `ItemConfig`

护甲数值表：
- `EquipmentConfig`

当前可直接绑定的 `ItemConfig` 字段：
- `Id`
- `Name`
- `Desc`
- `Icon`
- `Quality`
- `GridWidth`
- `GridHeight`
- `LoadoutShopVisible`
- `LoadoutShopCategory`
- `LoadoutBuyPrice`
- `CanEquipMainWeapon`
- `CanEquipSubWeapon`
- `CanEquipArmor`
- `CanEquipBackpack`
- `IsBackpack`
- `BackpackWidth`
- `BackpackHeight`

## 10. 制作建议
- 主界面优先做“固定槽位 + 仓库 + 背包 + 安全格 + 操作按钮”。
- 背包配置界面优先做“商店列表 + 背包/安全格草稿预览”。
- 固定槽位和网格物品尽量复用同一套物品卡片组件，减少后续绑定成本。
- 本期不支持旋转，尺寸展示和占格都按固定朝向制作即可。
