**涉及包**：cn.etetet.statesync

## 需求概述

当前 `EquipSelectView` 右侧预览区只有名称、图标和描述文本，起装时看不到武器关键数值，切装备前无法快速判断武器定位。

本轮需求范围明确为：

1. 仅改 `EquipSelectView` 右侧预览区。
2. 显示待选武器自身的关键属性，不做“当前装备 vs 待装备”的对比卡。
3. 非枪械或没有 `WeaponConfig` 的物品，继续保留名称、图标、描述的通用预览。
4. 非枪械不显示一堆默认值或 `0`。

## 技术方案

### 整体思路

先按 `yiui-unity-mcp` 口径检查了现有 `EquipSelectView.prefab` 的右侧结构，确认当前 `GunBg` 区域已经有稳定的“名称 + 图标 + 描述”预览骨架。

本轮不额外在 prefab 里再拆第二套固定属性面板，而是直接复用现有 `GunDesc` 文本容器，把它升级成：

1. 武器时显示“属性摘要 + 说明”复合文案。
2. 非武器时继续显示原描述文案。

这样做的原因：

1. 当前 `GunBg` 的标题、图标、描述布局已经定型，继续加独立属性块会牵涉 prefab 结构、YIUI 生成链和文案区重新排版。
2. 本次只要求显示“部分需要的武器属性”，不要求完整数值面板或多列对比。
3. 复用现有文案容器可以最小改动满足诉求，且不会引入非武器空白属性区。

### 显示字段

武器预览文案固定收口以下 6 项：

1. 武器类型 `WeaponTypeId`
2. 伤害 `Damage`
3. 射程 `AttackRange`
4. 射速 `1000 / AttackIntervalMs`
5. 弹匣 `MagazineSize`
6. 换弹时间 `ReloadTimeMs / 1000`

展示形式为压缩摘要：

- 第 1 行：类型 / 伤害 / 射程
- 第 2 行：射速 / 弹匣 / 换弹
- 第 3 行起：说明文案

### Entity/Component 设计

本次不新增 Entity，也不改协议、Excel、Proto。

1. 统一按 `itemData.ConfigId` 尝试读取 `WeaponConfig`。
2. 命中武器配置时，构造属性摘要文案。
3. 未命中武器配置时，保持原有通用描述逻辑。
