# M0 版本功能参考

**项目名称**：竖屏搜打撤
**创建时间**：2026-02-27
**最后更新**：2026-03-26

## 立项逻辑

方向是传统搜打撤的手游泛用户化改造，改造路径是竖屏单手减轻操作门槛、强化局内PVE和肉鸽成长体验。

## 项目概述

- **局外**：配装入局
- **局内目标**：
  - **前期**：搜索——增加带出的财富；击杀小怪——强化自身战力（增加等级 & 获得肉鸽牌）
  - **中后期**：击杀敌人——大幅增加带出的财富；撤离——带出财富
- **财富用途**：进更高爆率的图、做局外养成

## 版本规划

### M0（3个月）— MVP 版本

**版本目的**：验证 PVP 战斗体验和基础的搜打撤体验。

**技术选型**：选择 ET10 + WOW 包作为起始框架。

**需要改造的功能**：
1. 多模式匹配进图：PVE、1v1、3v3、搜打撤
2. 局外携带装备进图：枪械、选择英雄
3. 战斗 3C：摇杆移动、自动攻击、滑动释放指向技能、双击释放大招、点击武器格子选择不同武器
4. 关卡组件框架：ECA（Event Condition Action）架构，搜索容器 / 撤离点
5. 局内成长机制：待设计

**初版体验设计**：
1. 地图设计
2. 枪械数值和怪物数值
3. 英雄技能设计

### M1（1个月）— 中心内部试玩

**基础包装**：
1. 枪械手感和打击感、碰撞挤压
2. 正式版本 UI
3. 地图和角色模型细化、特效替换

**局外功能**：
1. 任务系统
2. 仓库和售卖、交易系统

### M2（2个月）— 公司内部试玩

1. 接入数据库
2. 断线重连
3. 排位上分模式
