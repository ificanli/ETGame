# 武器弹速配置化说明

> 创建时间：2026-04-10
> 关联需求：M0.2-W3 枪械数值调优

---

## 一、背景

不同武器的子弹速度应有差异（狙击枪快、火箭炮慢），但之前服务端子弹速度硬编码为 20 m/s，客户端已读取 `WeaponConfig.ProjectileSpeed` 配置值，导致弹道表现不一致。

### 改动前

| 端 | 弹速来源 | 值 |
|----|----------|-----|
| 客户端 | `WeaponConfig.ProjectileSpeed`，默认 30 | 配置化 |
| 服务端 | `BulletComponentSystem.Awake` 硬编码 | 固定 20 |

---

## 二、方案

让服务端子弹创建时也读取 `WeaponConfig.ProjectileSpeed`，通过参数传入 `BulletHelper.CreateBullet()`。

---

## 三、改动说明

### BulletHelper.cs

`CreateBullet` 和 `CreateScatterBullets` 新增可选参数 `float speed = 0f`：

```csharp
public static Unit CreateBullet(..., int penetrationCount = 0, float speed = 0f)
{
    // ...创建子弹组件后...
    if (speed > 0f)
    {
        bulletComp.Speed = speed;
    }
}
```

`speed <= 0` 时保留 `BulletComponentSystem.Awake` 中的默认值 20 m/s 作为兜底。

### BTWeaponFireHandler.cs

服务端开火逻辑读取配置弹速并传入：

```csharp
float bulletSpeed = weaponConfig.ProjectileSpeed > 0 ? weaponConfig.ProjectileSpeed : 20f;

// 传入 CreateBullet / CreateScatterBullets
BulletHelper.CreateBullet(scene, caster, target, damage, lockType, weaponId, penetration, bulletSpeed);
```

### 客户端 M2C_WeaponFireHandler.cs

已有逻辑，无需修改：

```csharp
float speed = weaponConfig.ProjectileSpeed > 0 ? weaponConfig.ProjectileSpeed : 30f;
```

> 客户端默认值 30 与服务端默认值 20 不同，这是因为客户端弹道为纯视觉表现，稍快可以提升打击感。

## 五、调参指南

修改 `Weapon.xlsx` 中 `ProjectileSpeed` 列即可。Luban 导出后服务端和客户端同时生效。

弹速影响：
- **命中时间**：距离 / 弹速 = 弹道飞行秒数
- **体感差异**：低弹速武器需要预判，高弹速武器接近即时命中
- **服务端判定**：弹速越低，子弹存活时间越长，判定延迟越大
