# 伤害流程与乘区规划

## 概述

所有伤害（武器子弹、技能法术）最终汇入统一管线 `DamageContextHelper.ApplyDamage()`，经过"基础伤害 → 增伤 → 减伤 → 致命判定 → 扣血 → 后置效果"六个阶段。

---

## 1. 伤害公式总览

```
最终伤害 = BaseDamage
         + Σ 攻击方增伤（加算）
         - Σ 防御方减伤（减算）
         → 致命免死判定
         → 实际扣血 = min(FinalDamage, CurrentHP)
```

### 基础伤害来源

| 来源 | 公式 | 说明 |
|------|------|------|
| **武器子弹** | `Attack × WeaponConfig.Damage / 100 × (1000 + RogueWeaponMod) / 1000` | Attack = NumericComponent 攻击力属性 |
| **技能法术** | BTDamage.Value > 0 ? 固定值 : `Attack × SpellConfig.DamageMultiplier / 100` | 向后兼容旧行为树固定伤害 |

### 攻击力属性（NumericType.Attack = 1010）

```
Attack = ((AttackBase + AttackAdd) × (100 + AttackPct) / 100 + AttackFinalAdd) × (100 + AttackFinalPct) / 100
```

| 二级属性 | ID | 说明 |
|---------|-----|------|
| AttackBase | 10101 | 基础攻击力（来自 Unit.xlsx KV） |
| AttackAdd | 10102 | 加算（Buff/装备提供的固定值） |
| AttackPct | 10103 | 百分比加算（如 +20% → 值为 20） |
| AttackFinalAdd | 10104 | 后置固定加算 |
| AttackFinalPct | 10105 | 后置百分比（如 +10% → 值为 10） |

攻击力变化时自动刷新武器有效伤害（`NumericChange_RefreshWeaponDamage`）。

## 2. 伤害管线全流程

```
┌─────────────────────────────────────────────────────┐
│ 伤害来源                                              │
│  ┌──────────┐    ┌──────────────┐                    │
│  │ 武器子弹  │    │ 技能法术      │                    │
│  │ BulletHit │    │ DamageHelper │                    │
│  └────┬─────┘    └──────┬───────┘                    │
│       ↓                  ↓                            │
│  BulletDamage      BeforeSpellDamage                 │
│  Request           Apply (拦截)                       │
│       ↓                  ↓                            │
│       └────────┬─────────┘                            │
│                ↓                                      │
│   DamageContextHelper.ApplyDamage()                  │
│                                                       │
│   Step 1: 创建 DamageContext                          │
│            BaseDamage = FinalDamage = 输入值          │
│                ↓                                      │
│   Step 2: 发布 RogueBeforeDamageApply                │
│            ├─ 攻击方增伤 ──────────────────┐          │
│            │  金币增伤、低血增伤、体型增伤    │          │
│            │  暴击加成、击杀叠层、即死       │          │
│            │  → 累加到 bonusDamage         │          │
│            │  → FinalDamage += bonusDamage │          │
│            │                               │          │
│            ├─ 防御方减伤 ──────────────────┐│          │
│            │  千分比/固定减伤、低血护盾      ││          │
│            │  → FinalDamage -= reduction   ││          │
│            │                               ││          │
│            └─ 致命免死 ────────────────────┐││          │
│               消耗金币 → CanDie = false    │││          │
│                ↓                           │││          │
│   Step 3: FinalDamage = max(0, FinalDamage)│││          │
│                ↓                           │││          │
│   Step 4: 计算实际扣血                      │││          │
│            newHp = currentHp - FinalDamage │││          │
│            if (newHp ≤ 0 && !CanDie)       │││          │
│                newHp = 1                   │││          │
│            ActualDamage = currentHp - newHp│││          │
│            TargetKilled = (newHp ≤ 0)      │││          │
│                ↓                                      │
│   Step 5: 写入 HP                                    │
│            target.NumericComponent.Set(HP, newHp)     │
│                ↓                                      │
│   Step 6: 发布 RogueAfterDamageApply                 │
│            ├─ 战斗状态更新                             │
│            ├─ 吸血回复 (ActualDamage × LifeSteal‰)   │
│            └─ 暴击成长                                 │
│                ↓                                      │
│   Step 7: if (TargetKilled) 发布 UnitDie              │
└─────────────────────────────────────────────────────┘
```

## 3. 乘区规划

### 当前乘区结构

伤害计算分为三个**独立乘区**，乘区之间相乘，乘区内部加算：

```
最终伤害 = 基础伤害 × (1 + Σ增伤‰/1000) × (1 - Σ减伤) × 暴击倍率
```

| 乘区 | 阶段 | 计算方式 | 修正来源 |
|------|------|---------|---------|
| **A 基础伤害** | 武器/技能层 | `Attack × 系数% × 武器Mod‰` | NumericComponent.Attack、WeaponConfig.Damage、RogueWeaponModifier(BulletDamage) |
| **B 增伤区（加算）** | BeforeDamageApply | 区内加算，最后加到 FinalDamage | 金币增伤、低血增伤、怪物增伤、体型增伤、击杀叠层 |
| **C 减伤区（减算）** | BeforeDamageApply | 区内加算，从 FinalDamage 减去 | 千分比减伤、固定减伤、低血护盾吸收 |
| **D 暴击** | BeforeDamageApply | 触发后 FinalDamage +100% | 暴击概率判定（仅子弹） |
| **E 即死** | BeforeDamageApply | 触发后 FinalDamage = 目标当前HP | 概率触发，仅对非Boss怪物 |

### 详细修正项

#### 乘区 A — 基础伤害

| 修正 | 来源 | 公式 | 文件 |
|------|------|------|------|
| 攻击力 | NumericComponent | 五属性公式 | NumericType.cs |
| 武器伤害系数 | WeaponConfig.Damage | `Attack × Damage / 100` | WeaponRuntimeStatsHelper.cs:67 |
| 肉鸽武器增伤 | RogueWeaponModifier(BulletDamage) | `× (1000 + mod) / 1000` | WeaponRuntimeStatsHelper.cs:68 |
| 换弹首发加伤 | RogueReloadFirstShotsState | `× (1000 + permille) / 1000` | BTWeaponFireHandler.cs:89 |

#### 乘区 B — 增伤区（均为加算，累加后一次性加到 FinalDamage）

| 修正 | 条件 | 公式 | 文件:行 |
|------|------|------|---------|
| 金币增伤 | 持有金币 | `FinalDmg × (Gold / GoldPerOnePercent) / 100` | DamageModifiers:59-71 |
| 低血增伤 | 目标HP < 阈值‰ | `FinalDmg × bonus‰ / 1000` | DamageModifiers:82-93 |
| 怪物增伤 | 目标为Monster | `FinalDmg × bonus‰ / 1000` | DamageModifiers:99-103 |
| 体型增伤 | 攻防体型差异 | `FinalDmg × bonus‰ / 1000`（有上限） | DamageModifiers:108-126 |
| 击杀叠层 | 有OnKillStack | `FinalDmg × stacks × permillePerStack / 1000` | DamageModifiers:202-210 |

#### 乘区 C — 减伤区

| 修正 | 条件 | 公式 | 文件:行 |
|------|------|------|---------|
| 千分比减伤 | Reduction ≤ 1000 | `FinalDmg × reduction‰ / 1000` | DamageModifiers:227-249 |
| 固定减伤 | Reduction > 1000 | 直接减去固定值 | DamageModifiers:227-249 |
| 低血护盾 | 目标HP% ≤ 触发阈值 | 护盾值 = `MaxHP × shield‰ / 1000`，吸收伤害 | DamageModifiers:272-320 |

#### 乘区 D — 暴击

| 修正 | 条件 | 公式 | 文件:行 |
|------|------|------|---------|
| 暴击 | IsBullet && 随机 < critChance‰ | `FinalDmg × 1000 / 1000` (+100% 固定) | DamageModifiers:129-142 |

#### 特殊 E — 即死

| 修正 | 条件 | 公式 | 文件:行 |
|------|------|------|---------|
| 即死 | 非Boss怪物 && 随机 < chance‰ | `FinalDamage = 目标当前HP` | DamageModifiers:144-194 |

## 4. 后置效果（AfterDamageApply）

| 效果 | 条件 | 公式 | 文件 |
|------|------|------|------|
| 战斗状态 | 攻击方/目标存在 | 标记进入战斗 | AfterDamageApply_UpdateCombatState |

## 7. 数值示例

以步枪为例，AttackBase=100，Damage=18（18%攻击力）：

```
基础伤害 = 100 × 18 / 100 = 18
         × (1000 + 0) / 1000 = 18 （无肉鸽武器Mod）

增伤：假设有 200‰ 金币增伤
  bonus = 18 × 200 / 1000 = 3.6
  FinalDamage = 18 + 3 = 21

减伤：假设目标有 100‰ 减伤
  reduction = 21 × 100 / 1000 = 2.1
  FinalDamage = 21 - 2 = 19

暴击：假设触发暴击（+100%）
  bonus = 19 × 1000 / 1000 = 19
  FinalDamage = 19 + 19 = 38

扣血：ActualDamage = min(38, currentHP)
```

Buff 加 20% 攻击力后：
```
Attack = (100 + 0) × (100 + 20) / 100 = 120
基础伤害 = 120 × 18 / 100 = 21.6
```
