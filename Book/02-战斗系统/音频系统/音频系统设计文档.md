# 音频系统设计文档

## 1. 概述

从零搭建 ET 框架客户端音频系统，覆盖 BGM、SFX、UI 三类音效。当前使用程序生成的正弦波占位音效，后续替换真实资源只需改配置。

## 2. 架构

```
AudioHelper (静态入口，一行调用)
  └─ AudioManagerComponent (Scene 级组件，挂在 root Scene 上)
       ├─ BgmSourceA / BgmSourceB   ── BGM 双 Source 交叉淡入
       ├─ SfxSources[8]             ── SFX 对象池，round-robin
       ├─ UiSource                  ── UI 专用 Source
       ├─ ClipCache                 ── AudioClip 缓存（key → clip）
       └─ AudioPlaceholderGenerator ── 占位音效生成器
```

### 2.1 组件与系统

| 文件 | 路径 | 职责 |
|------|------|------|
| `AudioManagerComponent.cs` | `ModelView/Client/` | 数据：AudioSource 引用、音量设置、缓存、crossfade 状态 |
| `AudioManagerComponentSystem.cs` | `HotfixView/Client/` | 逻辑：Awake 创建 AudioSource 池、Update 处理 crossfade、PlayBgm/PlaySfx/PlayUi |
| `AudioEventId.cs` | `ModelView/Client/` | 常量：所有音频 key，含 `GetFireSoundByWeaponType()` |
| `AudioPlaceholderGenerator.cs` | `HotfixView/Client/` | 工具：根据 key 中的关键词生成不同频率/时长的正弦波 AudioClip |
| `AudioHelper.cs` | `HotfixView/Client/` | 静态 Helper：懒初始化组件 + 一行调用封装 |

### 2.2 BGM 交叉淡入

- 双 AudioSource (A/B) 交替角色
- 调用 `PlayBgm(key)` 时：B 开始播放新 BGM（volume=0），Update 中 1.5 秒线性插值
- A 淡出到 0 → 停止，B 淡入到 BgmVolume → 成为新 A
- 快速切换时立即完成当前淡入再开始新的

### 2.3 SFX 对象池

- 8 个 AudioSource，round-robin 轮询
- 全部 2D（spatialBlend=0），M0.2 不需要 3D 音效
- 使用 `PlayOneShot` 避免打断前一个音效

### 2.4 懒初始化

`AudioHelper` 在首次调用时自动 `AddComponent<AudioManagerComponent>()`，无需手动挂载或事件注册。

## 3. P0 音频接入点清单（15 条）

### 3.1 通过并行 Handler 接入（不修改现有文件）

ET 框架支持同一消息类型注册多个 `MessageHandler`（`MessageDispatcher` 用 `List<MessageDispatcherInfo>` 存储），因此可创建独立的音频 Handler。

| 文件 | 需求 ID | 触发 |
|------|---------|------|
| `AudioHook_WeaponFire.cs` | AUD-006/007 步枪/冲锋枪射击 | `[MessageHandler] M2C_WeaponFire` → `AudioHelper.PlayWeaponFire(root, weaponConfig.WeaponTypeId)` |
| `AudioHook_WeaponHit.cs` | AUD-012 击中敌人 | `[MessageHandler] M2C_WeaponHit` → `AudioHelper.PlaySfx(SfxWeaponHit)` |
| `AudioHook_RogueEvents.cs` | AUD-017 升级 | `[MessageHandler] M2C_RogueLevelUp` → `AudioHelper.PlaySfx(SfxLevelUp)` |
| `AudioHook_RogueEvents.cs` | AUD-018 三选一弹出 | `[Event] EventRogueChoicePopup` → `AudioHelper.PlayUi(SfxChoicePopup)` |
| `AudioHook_Settlement.cs` | AUD-015/026 死亡/撤离 | `[Event] EventSettlementPopup` → 根据 `IsSuccess` 播 `SfxEvacSuccess` 或 `SfxPlayerDeath` |
| `AudioHook_ContainerOpen.cs` | AUD-021 搜索容器打开 | `[Event] ECAContainerOpenUIEvent` → `AudioHelper.PlayUi(SfxContainerOpen)` |

## 4. 占位音效说明

`AudioPlaceholderGenerator` 根据 key 中的关键词生成不同特征的正弦波：

| 类别 | 频率 | 时长 | 听感 |
|------|------|------|------|
| BGM | 220 Hz | 4s (循环) | 低沉嗡鸣 |
| 步枪开火 | 880 Hz | 0.08s | 高频短促 |
| 冲锋枪开火 | 1000 Hz | 0.06s | 更高更快 |
| 霰弹枪 | 600 Hz | 0.15s | 中频稍长 |
| 火箭炮 | 300 Hz | 0.25s | 低频较长 |
| 击中/受伤 | 1200 Hz | 0.08s | 尖锐极短 |
| 死亡/失败 | 150 Hz | 1s | 低沉下坠 |
| 升级/成功 | 660 Hz | 0.4s | 明亮上扬 |
| UI 点击 | 1000 Hz | 0.04s | 极短脆响 |
| 容器/面板 | 440 Hz | 0.15s | 中性短音 |

## 5. 替换真实资源指南

### 步骤

1. 将 `.wav` / `.ogg` 音频文件放入 YooAssets Bundle 目录（如 `Packages/cn.etetet.statesync/Bundles/Audio/`）
2. 确保文件路径与 `AudioEventId.cs` 中的 key 对应（如 `Audio/BGM/bgm_lobby`）
3. 将 `AudioManagerComponent.PlaceholderMode` 改为 `false`（在 `AudioManagerComponentSystem.Awake` 中）
4. 如需预加载：在场景初始化时调用 `ResourcesLoaderComponent.LoadAssetAsync<AudioClip>(key)` 缓存到 `ClipCache`

### 配置表方案（可选）

后续可将 `AudioEventId` 的 key→path 映射迁移到 Luban 配置表，实现数据驱动：

```
# AudioConfig.xlsx
| Id        | Key             | Path                          | Volume | Type |
|-----------|-----------------|-------------------------------|--------|------|
| AUD-001   | bgm_lobby       | Audio/BGM/bgm_lobby.ogg       | 0.5    | BGM  |
| AUD-006   | weapon_rifle1   | Audio/SFX/weapon_rifle1.wav    | 0.7    | SFX  |
```

## 6. API 参考

```csharp
// BGM
AudioHelper.PlayBgm(root, AudioEventId.BgmLobby);     // 交叉淡入
AudioHelper.PlayBgm(root, AudioEventId.BgmBattle);     // 自动淡出旧 BGM
AudioHelper.StopBgm(root);                              // 停止 BGM

// SFX
AudioHelper.PlaySfx(root, AudioEventId.SfxWeaponHit);   // 通用 SFX
AudioHelper.PlayWeaponFire(root, weaponConfig.WeaponTypeId); // 按武器类型

// UI
AudioHelper.PlayUi(root, AudioEventId.SfxUiClick);      // UI 专用通道
AudioHelper.PlayUi(root, AudioEventId.SfxChoiceConfirm);

// 静音
root.GetComponent<AudioManagerComponent>()?.SetMuted(true);
```
