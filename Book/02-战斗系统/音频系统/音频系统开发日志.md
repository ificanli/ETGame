# 音频系统开发日志

## 2026-03-30 初版实现

### 背景

项目有 52 条音频需求（见 `Book/概念-需求-设计文档/音频需求.xlsx`），但没有任何音频基础设施。本次从零搭建音频管理系统，先用占位音效覆盖 P0 的 15 条需求。

### 实现内容

#### Phase 1：核心系统（5 个新文件）

- `AudioManagerComponent.cs` — Scene 级组件，持有 BGM 双 Source、SFX 池(8个)、UI Source
- `AudioEventId.cs` — 定义所有 P0 音频 key 常量，含按武器类型返回音效的方法
- `AudioManagerComponentSystem.cs` — 完整系统逻辑：
  - Awake：创建 `[AudioManager]` GameObject + DontDestroyOnLoad + 所有 AudioSource
  - Update：BGM 交叉淡入（1.5 秒线性插值）
  - Destroy：清理 GameObject 和缓存
  - PlayBgm/StopBgm/PlaySfx/PlayUi/SetMuted API
- `AudioPlaceholderGenerator.cs` — 根据 key 关键词生成不同频率/时长的正弦波 AudioClip
- `AudioHelper.cs` — 静态一行调用，懒初始化 AudioManagerComponent

#### Phase 2：P0 并行 Handler（5 个新文件）

利用 ET 框架支持同消息类型多 Handler 的特性，创建独立的音频 Handler：

- `AudioHook_WeaponFire.cs` — 监听 M2C_WeaponFire，按 WeaponTypeId 播不同开火音
- `AudioHook_WeaponHit.cs` — 监听 M2C_WeaponHit，播击中反馈
- `AudioHook_RogueEvents.cs` — 监听 M2C_RogueLevelUp + EventRogueChoicePopup
- `AudioHook_Settlement.cs` — 监听 EventSettlementPopup，根据 IsSuccess 播不同音效
- `AudioHook_ContainerOpen.cs` — 监听 ECAContainerOpenUIEvent

#### Phase 3：现有文件单行改动（5 个文件）

- `LobbyPanelComponentSystem.cs` — YIUIOpen 加主界面 BGM
- `HUDPanelComponentSystem.cs` — YIUIOpen 加战斗 BGM（自动交叉淡入）
- `SearchPanelComponentSystem.cs` — YIUIOpen 加搜刮音效
- `SettlementPanelComponentSystem.cs` — RefreshView 加结算成功/失败音效
- `RoguePanelChoiceHelper.cs` — TryChooseOption 加选牌确认音效

### 编译修复

- `Object.DontDestroyOnLoad` → `UnityEngine.Object.DontDestroyOnLoad`（ET 框架全局 using 不含 UnityEngine.Object）
- `Object.Destroy` → `UnityEngine.Object.Destroy`（同上）

### 编译结果

`dotnet build ET.sln` — 成功，0 错误 0 警告。
