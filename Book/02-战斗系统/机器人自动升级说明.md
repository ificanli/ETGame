# 机器人自动升级说明

> 创建时间：2026-04-10
> 关联需求：M0.2-W3 枪械数值调优

---

## 一、背景

肉鸽模式中机器人（AI 控制的玩家角色）无法通过击杀怪物稳定获取经验。为了让机器人的等级增长与真实玩家节奏匹配，引入基于配置表的"时间→等级"自动升级机制。

---

## 二、配置表

**文件**：`Packages/cn.etetet.statesync/Luban/Config/Datas/RobotAutoLevel.xlsx`

| Id | TimeSec | Level | 说明 |
|----|---------|-------|------|
| 1 | 0 | 1 | 初始等级 |
| 2 | 30 | 2 | 30秒升2级 |
| 3 | 60 | 3 | 1分钟升3级 |
| 4 | 90 | 5 | 1.5分钟升5级 |
| 5 | 120 | 7 | 2分钟升7级 |
| 6 | 180 | 10 | 3分钟升10级 |
| 7 | 240 | 13 | 4分钟升13级 |
| 8 | 300 | 15 | 5分钟升15级 |

中间时间点通过**线性插值**计算目标等级（取整数）。例如：
- T=45s → lerp(2, 3, 0.5) = 2（取 floor）
- T=105s → lerp(7, 10, 0.25) = 7

超过最后一条配置（300s）后，维持最大等级 15 不再升级。

## 三、实现流程

```
机器人进入地图
  → MapUnitEnterHelper.SetupMatchRobotIfNeeded()
    → RobotAutoLevelHelper.StartAutoLevel(unit, matchRobot)
      → 启动 1 秒间隔重复定时器

每秒 Tick:
  → 计算局内经过秒数 = (ServerNow - MatchStartTime) / 1000
  → GetScaledElapsedSec(elapsedSec) 先按时间缩放系数压慢 AI 升级时间轴
  → ResolveTargetLevel(elapsedSec) 基于缩放后的秒数查表+线性插值
  → 若 progress.Level < targetLevel
    → EnsureLevelTo() 循环补发经验至目标等级
```

### 关键方法

| 方法 | 位置 | 作用 |
|------|------|------|
| `StartAutoLevel` | RobotAutoLevelHelper | 记录开始时间，启动定时器 |
| `Tick` | RobotAutoLevelHelper | 每秒检查是否需要升级 |
| `GetScaledElapsedSec` | RobotAutoLevelHelper | 先把原始经过秒数按统一系数缩放 |
| `ResolveTargetLevel` | RobotAutoLevelHelper | 查表+线性插值算目标等级 |
| `EnsureLevelTo` | RobotAutoLevelHelper | 循环 AddExp 直到达到目标等级 |

### 定时器清理

`MatchRobotComponent` 实现 `IDestroy`，销毁时自动清理定时器：

```csharp
[EntitySystem]
private static void Destroy(this MatchRobotComponent self)
{
    if (self.AutoLevelTimerId != 0)
    {
        self.GetParent<Unit>()?.Root()?.TimerComponent?.Remove(ref self.AutoLevelTimerId);
        self.AutoLevelTimerId = 0;
    }
}
```

## 四、与玩家升级的关系

机器人升级走的是 `RogueProgressHelper.AddExp()` → `LevelUp()` 的标准流程，与真实玩家完全一致：
- 触发选牌（`RogueChooseEntry`）→ 机器人有自动选牌延迟（`AutoChooseDelayMinMs/MaxMs`）
- 属性增量按 `RogueLevelNumericEntry` UnitType=1（玩家）的配置累加
- 升级同时刷新怪物显示等级（`RefreshMonsterDisplayLevels`），进而触发怪物属性成长

## 六、当前节奏调优口径

当前代码除了读取 `RobotAutoLevel.xlsx` 外，还额外增加了一层统一时间缩放：

```csharp
public const int AutoLevelElapsedTimeScalePermille = 800;
scaledElapsedSec = elapsedSec * AutoLevelElapsedTimeScalePermille / 1000;
```

这意味着机器人不会按“真实经过秒数”直接查表，而是按 `80%` 的时间轴推进等级。

示例：
- 原始经过 `90s` 时，实际按 `72s` 查表
- 原始经过 `120s` 时，实际按 `96s` 查表

这样做的目的，是优先放慢 AI 玩家把“存活玩家平均等级”抬高的速度，从源头减慢怪物成长节奏；怪物显示等级本身仍保持 `= 当前存活玩家平均等级` 的口径，不再单独做折算映射。

## 七、调参指南

调整优先级如下：

1. 优先改 `RobotAutoLevelHelper.AutoLevelElapsedTimeScalePermille`
2. 再改 `RobotAutoLevel.xlsx` 中的 `TimeSec / Level`

原因：
- 当前用户反馈的“怪物升级太快”，真实源头是 AI 平均等级增长过快
- 优先调 AI 时间轴，不会改动怪物显示等级口径，也不会误伤玩家经验表
- 由于当前仓库的全量 Luban 导表仍存在历史阻塞，代码常量比直接改表更稳妥

如果后续需要继续放慢或放快，可直接调整：

- `800` → 更小：AI 升级更慢
- `800` → 更大：AI 升级更快
- `1000`：完全恢复按原始配置表时间轴升级

注意事项：
- TimeSec 必须**升序排列**（Id 递增）
- Level 应**单调递增**，否则插值可能出现降级（当前实现不会主动降级，只在 `progress.Level < targetLevel` 时才升级）
- 机器人也会通过击杀怪物获取经验，如果击杀收益高于配置节奏，以实际等级为准（不会降级）
