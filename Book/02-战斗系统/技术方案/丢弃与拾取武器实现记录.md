> 关联设计：`长按丢弃武器技术方案.md`

## 1. 功能概述

| 操作 | 触发方式 | 效果 |
|------|---------|------|
| 丢弃武器 | 长按武器槽 UI ≥ 1 秒 | 武器从装备槽移除，地面生成可拾取物品，自动切换到另一把武器 |
| 拾取物品 | 靠近地面物品 → 点击 SearchButton | 武器且有空槽 → 直接装备；否则 → 放入背包 |

## 3. 服务端实现

### 3.1 丢弃流程 — WeaponDiscardHelper

**文件**：`Packages/cn.etetet.statesync/Scripts/Hotfix/Server/WeaponDiscardHelper.cs`

```
TryDiscardWeaponAsync(Unit unit, int slotIndex):
  1. 校验 slotIndex (1 或 2)、槽位有武器、非换弹中
  2. 从 EquipmentComponent 获取 Item → UnEquipItem → Dispose
  3. PlayerCorpseLootHelper.TryCreateGroundDrop() 创建地面物品
  4. 清空 WeaponComponent 槽位数据 + SetEffectiveStats(0)
  5. 自动切换：当前槽被丢 → 切到另一槽（有武器）或 CurrentSlot=0
  6. WeaponRuntimeStatsHelper.RefreshUnitWeaponRuntimeStats()
  7. 广播 M2C_WeaponDiscarded
```

**Handler**：`C2M_DiscardWeaponHandler.cs`
继承 `MessageLocationHandler<Unit, C2M_DiscardWeapon, M2C_DiscardWeapon>`

### 3.2 拾取流程 — WeaponPickupHelper

**文件**：`Packages/cn.etetet.statesync/Scripts/Hotfix/Server/WeaponPickupHelper.cs`

```
TryPickupGroundItemAsync(Unit unit, string pointId):
  1. ContainerRuntimeHelper.TryGetPoint() + IsPlayerInRange() 校验
  2. 从容器取第一个物品 ConfigId
  3. 判断是否武器（WeaponConfigCategory）
  4. 武器 + 有空武器槽 → TryEquipWeaponToEmptySlot():
     a. 找空槽（Slot1 或 Slot2）
     b. 创建 Item → EquipmentComponent.EquipItem()
     c. 更新 WeaponComponent 槽位数据 + SetEffectiveStats
     d. 广播 M2C_SwitchWeapon + M2C_WeaponAmmoState
     e. 从容器移除 → 清理空容器
  5. 否则 → ContainerRuntimeHelper.TakeAll() 放入背包
```

**Handler**：`C2M_PickupGroundItemHandler.cs`
继承 `MessageLocationHandler<Unit, C2M_PickupGroundItem, M2C_PickupGroundItem>`

## 4. 客户端实现

### 4.1 长按丢弃

**修改文件**：
- `WeaponItemComponent.cs` — 新增 `PressStartTime`, `IsPressing`, `LongPressThreshold = 1.0f`
- `WeaponItemComponentSystem.cs` — 新增 `BindLongPress()` 方法

**实现方式**：在 `YIUIInitialize` 中通过 `EventTrigger` 绑定 PointerDown / PointerUp / PointerExit：
- PointerDown → 记录 `PressStartTime`
- PointerUp → 判断按压时长 ≥ 1 秒 → 调用 `WeaponDiscardClientHelper.RequestDiscardWeapon`
- PointerExit → 取消长按
- 现有 Click 事件（`OnEventClickInvoke`）中检测按压时长，长按后跳过切换

**客户端请求**：`WeaponDiscardClientHelper.RequestDiscardWeapon(root, slotIndex)` — RPC Call

**新建**：`EventWeaponDiscarded_RefreshWeaponBar.cs`
监听 `EventWeaponDiscarded` → 刷新 WeaponBar UI

## 7. 测试要点

### 丢弃
1. 长按武器槽 ≥ 1 秒 → 武器消失，地面出现掉落物
2. 短按 < 1 秒 → 切换武器（不丢弃）
3. 丢弃当前武器 → 自动切换到另一把
4. 两把都丢 → CurrentSlot=0，空手状态
5. 空槽长按 → 无反应
6. 换弹中长按 → 拒绝丢弃

### 拾取
7. 靠近地面武器 → SearchButton 显示
8. 点击拾取（空手/有空槽）→ 武器直接装备到空槽
9. 点击拾取（双手满）→ 物品进入背包
10. 拾取后地面物品消失
11. 离开范围 → SearchButton 消失
