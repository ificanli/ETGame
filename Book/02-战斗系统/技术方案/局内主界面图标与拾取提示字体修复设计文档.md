# 局内主界面图标与拾取提示字体修复设计文档

**创建时间**：2026-04-16
**最后更新**：2026-04-17
**状态**：已完成
**关联任务**：M0.2-W3 #40
**涉及包**：cn.etetet.statesync

## 需求概述

修复三个局内 UI 表现问题：

1. `MainPanel` Buff 区当前显示白块，应该显示对应 Buff 图标。
2. `MainPanel` 武器栏当前显示白块，应该显示对应武器图标。
3. `PickupHintPanel` 当前文字使用英文字体，中文显示观感不对，需要切到项目现有中文字体。

本次修复优先走 prefab 真实层级和现有资源，不做运行时硬编码兜底。

## 技术方案

### 整体思路

先核对 prefab 真实节点，再让运行时代码绑定到正确的图标位。

- Buff 区：`MainPanel` 的 4 个 Buff 按钮实际复用 `ActionBarSlot.prefab`，真实图标节点是子节点 `Icon`，不是按钮根节点。因此改为优先取 `Icon` 子节点的 `Image`。
- 武器栏：`WeaponItem.prefab` 目前只有 `WeaponBg` 和 `WeaponSelect`，缺少独立武器图标节点，导致背景和图标职责混在一起。本轮在 prefab 中新增 `WeaponIcon`，代码里把“背景着色”和“图标换 sprite”拆开。
- 武器图标资源 key：局内武器栏不能再按 `WeaponType -> weapon_autorifle/weapon_shotgun...` 这套旧 key 取图，而要和当前 `Item.xlsx / ItemConfigCategory.json / YIUIAtlasData.asset` 对齐，优先直接使用 `ItemConfig.Icon` 中的正式 key（当前为 `weapon_50001~weapon_50011`）。
- 拾取提示：`PickupHintPanel.prefab` 当前使用 `LiberationSans SDF`，改为项目里已在中文 UI 使用的 `江城圆体 600W_爱给网_aigei_com SDF`。

### Entity/Component 设计

不新增新的 Entity 或 Component 类型，只扩展 `WeaponItemComponent` 的本地缓存字段：

- `BackgroundImage`：缓存 `WeaponBg`
- `IconImage`：缓存新增的 `WeaponIcon`

### 数据结构

不新增 Excel、Proto 或运行时配置。

沿用项目现有字体资源：

- 中文字体：`江城圆体 600W_爱给网_aigei_com SDF`
- guid：`47de09e09fe22734d84ab99f4daa9271`

## 实现步骤

1. 修正 Buff 按钮图标绑定，优先命中 `ActionBarSlot/Icon`。
2. 在 `WeaponItem.prefab` 中补独立 `WeaponIcon`，并把武器背景和图标职责拆开。
3. 将 `PickupHintPanel` 的 TMP 字体切到项目现有中文字体。
4. 执行 `dotnet build ET.sln` 验证。
