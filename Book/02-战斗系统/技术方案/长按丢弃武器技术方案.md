# 长按丢弃武器技术方案

> 文档版本：v1.0  
> 创建时间：2026-03-26  
> 关联需求：FEAT-001

---

## 1. 需求描述

玩家在游戏内**长按武器槽位图标（0.5 秒）**，触发丢弃当前武器的逻辑：
- 武器从装备槽（EquipmentComponent）移除；
- 武器实体掉落到玩家当前位置，生成地面拾取点（Ground Drop）；
- WeaponComponent 对应槽位清空（WeaponId → 0，弹药 → 0）；
- 客户端 UI 同步刷新武器槽位（空槽状态）。

---

## 2. 现状梳理

### 2.1 武器数据结构

```
Unit
 ├── EquipmentComponent           // 装备槽管理
 │    ├── MainHand → Item(slot1武器)
 │    └── OffHand  → Item(slot2武器)
 └── WeaponComponent              // 战斗运行时状态
      ├── Slot1WeaponId / Slot1Ammo
      └── Slot2WeaponId / Slot2Ammo
```

武器以 **Item 实体**的形式挂在 `EquipmentComponent` 的字典里（不在背包 ItemComponent 中）。

### 2.2 已有能力

| 能力 | 代码位置 |
|------|---------|
| 长按手势（一次触发） | `UIEventBindPress`（`cn.etetet.yiuiframework`），默认 0.5s |
| 物品丢弃到地面 | `ItemHelper.TryDiscardItemToGroundAsync(unit, itemId, count)` |
| 武器切换协议 | `C2M_SwitchWeapon` → `C2M_SwitchWeaponHandler` |
| 物品丢弃协议 | `C2M_DiscardItem` → `C2M_DiscardItemHandler` |
| 客户端武器槽点击事件 | `WeaponItemComponentSystem.OnEventClickInvoke` |

### 2.3 关键问题

`ItemHelper.TryDiscardItemToGroundAsync` 要求物品在**背包（ItemComponent）**中，而武器当前在 `EquipmentComponent` 中，**不在背包里**。因此不能直接复用该接口，需要新增"装备槽直接落地"路径。

---

## 3. 技术方案

### 3.1 总体流程

```
[客户端] 长按 WeaponSelect → OnEventLongPressInvoke(SlotIndex)
    ↓
发送 C2M_DiscardWeapon { SlotIndex }
    ↓
[服务端] C2M_DiscardWeaponHandler
    ├── 1. 从 EquipmentComponent 获取对应槽位 Item
    ├── 2. EquipmentComponent.UnEquipItem(slotType)  // 从装备槽移除
    ├── 3. PlayerCorpseLootHelper.TryCreateGroundDrop(unit, item)  // 掉落到地面
    ├── 4. item.Dispose()  // 销毁 Item 实体
    ├── 5. 更新 WeaponComponent 槽位（WeaponId=0，Ammo=0）
    ├── 6. 重算武器运行时参数 WeaponRuntimeStatsHelper.RefreshUnitWeaponRuntimeStats
    └── 7. 广播 M2C_DiscardWeapon { UnitId, SlotIndex }
    ↓
[客户端] M2C_DiscardWeaponHandler
    └── 刷新 WeaponBar UI（调用已有 RefreshSlot）
```

### 3.2 协议定义

新增协议文件（放在 `StateSync_C_10700.proto` 同目录）：

```proto
// 丢弃武器请求（客户端→服务端）
message C2M_DiscardWeapon {
    int32 RpcId    = 1;
    int32 SlotIndex = 2;   // 1=主手, 2=副手
}

// 丢弃武器响应（服务端→客户端）
message M2C_DiscardWeapon {
    int32 RpcId  = 1;
    int32 Error  = 2;
}

// 丢弃武器广播（通知其他玩家）
message M2C_WeaponDiscarded {
    int64 UnitId   = 1;
    int32 SlotIndex = 2;
}
```

> **建议 Opcode 区段**：在 `StateSync_C_10700` 段尾追加三条，与武器切换（10701~10703）相邻。

### 3.3 服务端实现

#### 3.3.1 新建 Handler

文件路径：`Packages/cn.etetet.statesync/Scripts/Hotfix/Server/C2M_DiscardWeaponHandler.cs`

```csharp
namespace ET.Server
{
    [MessageHandler(SceneType.Map)]
    public class C2M_DiscardWeaponHandler : MessageLocationHandler<Unit, C2M_DiscardWeapon, M2C_DiscardWeapon>
    {
        protected override async ETTask Run(Unit unit, C2M_DiscardWeapon request, M2C_DiscardWeapon response)
        {
            response.Error = await WeaponDiscardHelper.TryDiscardWeaponAsync(unit, request.SlotIndex);
            await ETTask.CompletedTask;
        }
    }
}
```

#### 3.3.2 新建 WeaponDiscardHelper

文件路径：`Packages/cn.etetet.statesync/Scripts/Hotfix/Server/WeaponDiscardHelper.cs`

```csharp
namespace ET.Server
{
    public static class WeaponDiscardHelper
    {
        public static async ETTask<int> TryDiscardWeaponAsync(Unit unit, int slotIndex)
        {
            if (unit == null || unit.IsDisposed)
                return ErrorCode.ERR_Cancel;

            if (slotIndex != 1 && slotIndex != 2)
                return ErrorCode.ERR_Cancel;

            WeaponComponent weaponComp = unit.GetComponent<WeaponComponent>();
            if (weaponComp == null)
                return ErrorCode.ERR_Cancel;

            // ① 获取对应装备槽
            EquipmentComponent equipComp = unit.GetComponent<EquipmentComponent>();
            if (equipComp == null)
                return ErrorCode.ERR_Cancel;

            EquipmentSlotType slotType = slotIndex == 1
                ? EquipmentSlotType.MainHand
                : EquipmentSlotType.OffHand;

            Item weaponItem = equipComp.GetEquippedItem(slotType);
            if (weaponItem == null || weaponItem.IsDisposed)
                return ErrorCode.ERR_ItemNotFound;

            long itemId     = weaponItem.Id;
            int  configId   = weaponItem.ConfigId;

            // ② 从装备槽移除（不放回背包）
            equipComp.UnEquipItem(slotType);

            // ③ 生成地面掉落（复用 PlayerCorpseLootHelper 地面掉落逻辑）
            bool dropped = PlayerCorpseLootHelper.TryCreateGroundDrop(
                unit,
                configId,
                count: 1,
                out string pointId);

            // ④ 销毁 Item 实体
            weaponItem.Dispose();

            // ⑤ 清空 WeaponComponent 槽位
            if (slotIndex == 1)
            {
                weaponComp.Slot1WeaponId = 0;
                weaponComp.Slot1Ammo     = 0;
                weaponComp.Slot1Reloading = false;
                weaponComp.SetEffectiveStats(1, 0f, 0, 0, 0, 0f);
            }
            else
            {
                weaponComp.Slot2WeaponId = 0;
                weaponComp.Slot2Ammo     = 0;
                weaponComp.Slot2Reloading = false;
                weaponComp.SetEffectiveStats(2, 0f, 0, 0, 0, 0f);
            }

            // 如果丢弃的是当前槽，切换到另一槽（如果有武器）
            if (weaponComp.CurrentSlot == slotIndex)
            {
                int otherSlot = slotIndex == 1 ? 2 : 1;
                int otherWeaponId = otherSlot == 1 ? weaponComp.Slot1WeaponId : weaponComp.Slot2WeaponId;
                weaponComp.CurrentSlot = otherWeaponId > 0 ? otherSlot : 0;
            }

            // ⑥ 重算武器运行时参数
            WeaponRuntimeStatsHelper.RefreshUnitWeaponRuntimeStats(unit);

            // ⑦ 通知装备槽移除
            NotifyEquipmentRemoved(unit, slotType);

            // ⑧ 广播丢弃事件（含自身，让自己 UI 也刷新）
            M2C_WeaponDiscarded discardMsg = M2C_WeaponDiscarded.Create();
            discardMsg.UnitId    = unit.Id;
            discardMsg.SlotIndex = slotIndex;
            MapMessageHelper.NoticeClient(unit, discardMsg, NoticeType.Broadcast);

            Log.Info($"[WeaponDiscard] unit={unit.Id}, slot={slotIndex}, configId={configId}, dropped={dropped}, pointId={pointId ?? "none"}");

            await ETTask.CompletedTask;
            return ErrorCode.ERR_Success;
        }

        private static void NotifyEquipmentRemoved(Unit unit, EquipmentSlotType slotType)
        {
            M2C_UpdateEquipment msg = M2C_UpdateEquipment.Create();
            msg.SlotType = -1;  // -1 = 卸下
            msg.ItemId   = 0;
            msg.ConfigId = 0;
            MapMessageHelper.NoticeClient(unit, msg, NoticeType.Self);
        }
    }
}
```

> **注意**：`PlayerCorpseLootHelper.TryCreateGroundDrop` 是否已有"仅生成掉落点"的重载，需根据实际实现确认。如果没有，可参考 `ItemDiscardToGroundEvent` 的发布方式（`ItemHelper.TryDiscardItemToGroundAsync` 的 Event 分发流程），或直接在 `WeaponDiscardHelper` 内内联地面掉落逻辑。

### 3.4 客户端实现

#### 3.4.1 WeaponItemComponent 新增长按事件

**文件**：`WeaponItemComponent.cs`（ModelView）

在现有 `OnEventClickInvoke` 常量之后追加：

```csharp
// 长按事件名（YIUI 自动绑定）
public const string OnEventLongPressInvoke = "WeaponItemComponent_OnEventLongPress";
```

**文件**：`WeaponItemComponentSystem.cs`（HotfixView）

新增长按事件处理方法：

```csharp
/// <summary>
/// 武器槽位长按事件（丢弃武器）
/// </summary>
[YIUIInvoke(WeaponItemComponent.OnEventLongPressInvoke)]
private static async ETTask OnEventLongPressInvoke(this WeaponItemComponent self)
{
    Scene root = self.Root();
    if (root == null || root.IsDisposed)
    {
        await ETTask.CompletedTask;
        return;
    }

    if (self.SlotIndex <= 0)
    {
        await ETTask.CompletedTask;
        return;
    }

    // 检查该槽位是否有武器（空槽不响应）
    WeaponComponent weaponComp = UnitHelper.GetMyUnitFromCurrentScene(root.Scene())?
        .GetComponent<WeaponComponent>();
    int weaponId = self.SlotIndex == 1
        ? weaponComp?.Slot1WeaponId ?? 0
        : weaponComp?.Slot2WeaponId ?? 0;

    if (weaponId <= 0)
    {
        await ETTask.CompletedTask;
        return;
    }

    // 发送丢弃武器请求
    C2M_DiscardWeapon request = C2M_DiscardWeapon.Create();
    request.SlotIndex = self.SlotIndex;
    await root.GetComponent<SessionComponent>()?.Session
        .Call(request) as M2C_DiscardWeapon;

    await ETTask.CompletedTask;
}
```

#### 3.4.2 WeaponItem.prefab 添加长按绑定

在 `WeaponItem.prefab` 的 `WeaponSelect`（当前已有 Click 绑定的对象）上：
1. 再添加一个 `UIEventBindPress` 组件；
2. 设置 `m_PressTime = 0.5`（默认值）；
3. 在 Inspector 中将事件绑定到 `OnEventLongPressInvoke`。

> `WeaponSelect` 同时承载 Click（`UIEventBind`）和 LongPress（`UIEventBindPress`），两者不冲突：
> - 短按 < 0.5s：`OnPointerUp` 取消倒计时，触发正常 Click；
> - 长按 ≥ 0.5s：`PressEnd` 回调触发，Click 事件不会发生（`OnPointerUp` 在 `PressEnd` 之后才调用，不重复派发）。

#### 3.4.3 处理 M2C_WeaponDiscarded

新建 `M2C_WeaponDiscardedHandler.cs`（Client）：

```csharp
namespace ET.Client
{
    [MessageHandler(SceneType.Current)]
    public class M2C_WeaponDiscardedHandler : MessageHandler<Scene, M2C_WeaponDiscarded>
    {
        protected override async ETTask Run(Scene scene, M2C_WeaponDiscarded message)
        {
            // 找到对应 Unit，刷新其武器 UI
            Unit unit = scene.GetComponent<UnitComponent>()?.Get(message.UnitId);
            if (unit == null || unit.IsDisposed)
            {
                await ETTask.CompletedTask;
                return;
            }

            // 自己：刷新武器栏 UI
            Unit myUnit = UnitHelper.GetMyUnitFromCurrentScene(scene);
            if (myUnit != null && myUnit.Id == message.UnitId)
            {
                WeaponBarHelper.RefreshWeaponBar(scene);
            }

            await ETTask.CompletedTask;
        }
    }
}
```

## 4. 边界情况处理

| 场景 | 处理方式 |
|------|---------|
| 槽位无武器，长按 | 客户端提前判断 `weaponId <= 0`，直接 return，不发请求 |
| 丢弃当前槽位的武器 | 服务端自动切换到另一槽（有武器则切，无武器则 CurrentSlot=0） |
| 丢弃后背包满（地面无法落地） | `TryCreateGroundDrop` 返回 false，仍销毁装备槽 Item（武器消失），日志 Warning |
| 换弹中丢弃武器 | 服务端在 `TryDiscardWeaponAsync` 开头检查 `weaponComp.CurrentReloading`，若正在换弹则返回错误码 `ERR_Cancel`，客户端静默忽略 |
| 网络延迟重复请求 | Handler 在获取 `GetEquippedItem` 时若已为 null，返回 `ERR_ItemNotFound`，客户端无二次请求逻辑 |

## 6. 测试要点

1. **正常丢弃**：长按主手/副手武器槽 0.5s，武器消失，地面出现掉落点，其他玩家可捡取；
2. **UI 刷新**：丢弃后武器槽显示空槽（图标消失，弹药显示"-"）；
3. **丢弃当前武器**：自动切换到另一槽（若有），武器槽选中框跟着切换；
4. **两把武器全丢**：两个槽位均为空，CurrentSlot=0，无自动射击；
5. **空槽长按**：无任何反应（不发请求）；
6. **换弹中长按**：操作被拒，武器不消失；
7. **短按不误触**：短按 < 0.5s 仍为切换武器，不触发丢弃。
