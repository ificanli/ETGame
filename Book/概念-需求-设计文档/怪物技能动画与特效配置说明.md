# 怪物技能动画与特效配置说明

**创建时间**：2026-03-28
**最后更新**：2026-04-10
**状态**：已完成
**关联设计**：[怪物技能与AI设计文档.md](./怪物技能与AI设计文档.md)
**适用范围**：当前 5 只怪物首版技能表现配置、后续怪物技能表现接入

---

## 目标

这份文档只解决一件事：

- 以后要给怪物技能补动画、预警、弹道、命中特效时，应该改哪一层、改哪些字段、当前 5 只怪各自该挂在哪个 `SpellId / BuffId` 上。

当前项目里，技能表现不是集中配在一个“特效表”里，而是分成 3 层：

1. `SpellConfig`
   - 决定技能入口、CD、目标选择、技能指示器。
2. `BuffConfig`
   - 决定前摇、延迟、命中、客户端动画、客户端特效。
3. 单位 Prefab / Animator / BindPoint
   - 决定动画参数是否存在、特效挂点是否存在、资源能不能正确播放。

当前正式入口补充：

1. 这 5 只怪已经不再从 `MonsterRuntimeProfileHelper` 运行时注册技能/AI。
2. 现在要改怪物技能表现，正式入口是 `Packages/cn.etetet.statesync/Assets/BT/Spell/*/*.asset` 里的 `SpellScriptableObject / BuffScriptableObject`。
3. AI 行为入口是 `Packages/cn.etetet.statesync/Assets/BT/AI/330101.asset` ~ `330105.asset`。
4. 资产改完后，正式导出结果是 `Packages/cn.etetet.map/Bundles/Json/SpellConfigCategory.txt` 和 `BuffConfigCategory.txt`。

---

## 一句话结论

- 要改“选目标时的红圈/扇形/落点提示”，改 `SpellConfig.TargetSelector.SpellIndicator`。
- 要改“施法动作 / 持续引导动作 / 特效播放 / 弹道飞行 / 命中特效”，改 `BuffConfig.Effects` 里的 `EffectClientBuffAdd / EffectClientBuffRemove`。
- 要改“实际伤害、延迟、范围、子技能链路”，改 `BuffConfig` 的服务端节点，不属于纯表现层。
- 不要再去改 `MonsterRuntimeProfileHelper` 配技能，那边现在只保留旧 groupId 兼容映射和战斗筛选辅助。

## 配置层级说明

### 1. SpellConfig 层

用途：

- 定义技能 ID、Buff ID、CD。
- 定义客户端目标选择方式。
- 定义目标选择时显示的技能指示器。

常用字段：

- `Id`
- `BuffId`
- `CD`
- `TargetSelector`

表现相关入口：

- `TargetSelectorPosition.SpellIndicator`
- `TargetSelectorCircle.SpellIndicator`
- `TargetSelectorSector.SpellIndicator`
- `TargetSelectorRectangle.SpellIndicator`

适合在这一层配置的内容：

- 地面红圈
- 落点圆圈
- 扇形预警
- 矩形预警

不适合在这一层配置的内容：

- 出手动画
- 挂在角色身上的持续特效
- 弹道特效
- 命中特效

---

### 2. BuffConfig 层

用途：

- 真正决定技能的时序。
- 用 Buff 实现前摇、读条、延迟爆炸、持续引导、命中后追加效果。
- 客户端动画和特效也挂在这里。

关键规则：

- 服务端逻辑放在 `EffectServerBuffAdd / Tick / Remove / Hitted`。
- 客户端表现放在 `EffectClientBuffAdd / Remove`。
- 如果 `BuffConfig.NoticeType = NoNotice`，客户端收不到这个 Buff，动画和特效就不会播。
- 需要客户端表现的 Buff，通常要设成 `NoticeType.Broadcast`。

当前项目的典型结构：

1. 主技能挂一个前摇 Buff。
2. 前摇 Buff 的 `EffectClientBuffAdd` 播动画和预警特效。
3. 前摇 Buff 到时间移除。
4. `EffectServerBuffRemove` 触发子技能或直接伤害。
5. 命中 Buff 再播命中特效。

---

### 3. 单位 Prefab / Animator / BindPoint 层

用途：

- 决定客户端表现配置能不能真正播出来。

必须满足的条件：

- Prefab 上必须能找到 `Animator`。
- `AnimatorController` 里必须有对应参数。
- `BindPointComponent` 里必须有你要挂特效的绑点。
- 特效资源名必须唯一，并且能被资源加载器按名字找到。

如果这一层没配好，代码通常不会报致命错，只会表现成“技能逻辑正常，但动画/特效没播”。

## 动画怎么配

### 动画参数来源

当前动画节点不是手填字符串，而是走 `MotionType` 枚举。

常用枚举：

- `MeleeAttack1`
- `MeleeAttack2`
- `MeleeAttack3`
- `SpellCastDirected`
- `ReadySpellDirected`
- `SpellCastOmni`
- `ReadySpellOmni`
- `GetHit`
- `Dead`

要求：

- Animator 参数名必须和 `MotionType.ToString()` 一致。
- 例如想播前摇施法，就要在 Animator 里有 `ReadySpellDirected` 或 `ReadySpellOmni`。
- 想播一次近战挥击，就要有 `MeleeAttack1`。

### 常用动画节点

- `BTAnimatorSetTrigger`
  - 用于播一次动作。
- `BTAnimatorSetBool`
  - 用于开启/关闭持续状态。
- `BTAnimatorSetFloat`
  - 用于设置浮点动画参数。
- `BTAnimatorSetInt`
  - 用于设置整型动画参数。

### 推荐模式

#### 一次性出手动作

```csharp
new EffectClientBuffAdd
{
    Children =
    {
        new BTAnimatorSetTrigger
        {
            Unit = "Caster",
            MotionType = MotionType.MeleeAttack1,
        },
    },
}
```

#### 引导/持续前摇动作

```csharp
new EffectClientBuffAdd
{
    Children =
    {
        new BTAnimatorSetBool
        {
            Unit = "Unit",
            MotionType = MotionType.ReadySpellDirected,
            Value = true,
        },
    },
},
new EffectClientBuffRemove
{
    Children =
    {
        new BTAnimatorSetBool
        {
            Unit = "Unit",
            MotionType = MotionType.ReadySpellDirected,
            Value = false,
        },
    },
}
```

## 特效怎么配

### 1. 角色挂点特效

适合：

- 手上蓄力光
- 身上 Buff 环
- 命中受击火花

节点：

- `BTCreateBuffEffect`

关键字段：

- `Unit`
- `Buff`
- `BindPoint`
- `Effect`
- `Duration`

示例：

```csharp
new EffectClientBuffAdd
{
    Children =
    {
        new BTCreateBuffEffect
        {
            Unit = "Caster",
            Buff = "Buff",
            BindPoint = BindPoint.Attack,
            Effect = new OdinUnityObject { Name = "effect_blade_charge" },
            Duration = 400,
        },
    },
}
```

---

### 2. 地面位置特效

适合：

- 红圈预警
- 爆炸落点
- 地面持续区

节点：

- `BTGetSpellTargetPos`
- `BTCreateEffectOnPos`

示例：

```csharp
new EffectClientBuffAdd
{
    Children =
    {
        new BTGetSpellTargetPos
        {
            Buff = "Buff",
            Pos = "Pos",
        },
        new BTCreateEffectOnPos
        {
            Pos = "Pos",
            Effect = new OdinUnityObject { Name = "effect_warning_circle_red" },
            Duration = 900,
        },
    },
}
```

---

### 3. 飞行弹道特效

适合：

- 飞镖
- 投掷物
- 拳风 / 冰箭 / 子弹替代演出

节点：

- `BTCreateFakeBullet`

关键字段：

- `Caster`
- `Target`
- `CasterBindPoint`
- `TargetBindPoint`
- `Speed`
- `Effect`

示例：

```csharp
new EffectClientBuffAdd
{
    Children =
    {
        new BTAnimatorSetTrigger
        {
            Unit = "Caster",
            MotionType = MotionType.SpellCastDirected,
        },
        new BTCreateFakeBullet
        {
            Caster = "Caster",
            Target = "Unit",
            CasterBindPoint = BindPoint.Attack,
            TargetBindPoint = BindPoint.Hitted,
            Speed = 30000,
            Effect = new OdinUnityObject { Name = "effect_phantom_dagger" },
            Duration = 3000,
        },
    },
}
```

## 技能指示器怎么配

这部分只在 `TargetSelector` 上配。

### 位置类技能

- `TargetSelectorPosition.SpellIndicator`

适合：

- 红圈落点
- 指定地点爆炸

### 圆形技能

- `TargetSelectorCircle.SpellIndicator`

适合：

- 以某个目标点或单位为中心的圆形范围提示

### 扇形技能

- `TargetSelectorSector.SpellIndicator`

适合：

- 重装鳄鱼这类前方扇形喷射

说明：

- 指示器只负责“瞄准阶段的提示”。
- 真正出手后的落地特效，仍然建议放到 `EffectClientBuffAdd` 里。

## 资源命名规则

### OdinUnityObject 的规则

- `Effect`、`Icon`、`SpellIndicator` 最终只存资源名 `Name`
- 运行时按名字查资源
- 不建议重名

建议命名：

- `effect_monster_bladecat_charge`
- `effect_monster_bladecat_hit`
- `effect_monster_monkey_bomb_warning`
- `effect_monster_monkey_bomb_explode`
- `effect_monster_owl_dagger`
- `effect_monster_gator_sector`
- `effect_monster_baloo_punch_charge`
- `effect_monster_baloo_bombard_warning`

## 自检清单

每次配完表现后，至少检查下面这些点：

1. `BuffConfig.NoticeType` 是否是 `Broadcast`
2. 动画参数名是否真的存在于 Animator Controller
3. 对应 Prefab 上是否真的有 `Animator`
4. 对应 Prefab 上是否真的有 `BindPointComponent`
5. 你填的 `BindPoint` 在 Prefab 上是否存在
6. `OdinUnityObject.Name` 对应资源名是否唯一
7. 红圈 / 扇形提示是否配在 `TargetSelector.SpellIndicator`，而不是错配到 Buff 特效
8. 命中特效是否挂在命中 Buff，而不是挂在目标选择阶段
9. 前摇动作是否挂在前摇 Buff，而不是挂到伤害 Buff
10. 资源改完后，是否重新导出并确认 `SpellConfigCategory.txt / BuffConfigCategory.txt` 已更新

---

## 当前最推荐的工作方式

对于你现在这批怪，建议按下面顺序调：

1. 先定每个技能的“前摇 Buff / 命中 Buff / 持续 Buff”分别是谁。
2. 再给每个 Buff 补客户端效果。
3. 再回 Unity 检查：
   - Animator 参数
   - BindPoint
   - Effect Prefab 名字
4. 最后进场景只验 4 件事：
   - 动画有没有播
   - 指示器有没有出
   - 特效挂点对不对
   - 命中时机和表现是否一致
