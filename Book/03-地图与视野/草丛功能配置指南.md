# 草丛功能配置指南

## 1. 功能概述

草丛（范围遮蔽）允许玩家进入特定区域后对区域外的其他玩家隐身。核心规则：

- 草丛外玩家 **看不到** 草丛内玩家
- 草丛内玩家 **能看到** 草丛外玩家
- 同一草丛内的多个玩家 **互相可见**
- 进入草丛后自身角色变半透明（仅本地表现，alpha 0.5）

系统被抽象为"范围遮蔽可见性"（Range Concealment Visibility），未来可复用于烟雾弹、主动隐身等机制。

## 2. 系统架构

```
┌─ Unity 场景 ─────────────────────────────────────────┐
│  ECAPointMarker (MonoBehaviour)                       │
│    ├─ ConfigId: "eca_sdcmap_grass_001"                │
│    ├─ Type: RangeTrigger (5)                          │
│    ├─ Params: interact_range = 3                      │
│    └─ FlowGraph: GrassBushFlow.asset                  │
└───────────────────────────────────────────────────────┘
        │ ET → ECA → Export ECA Config
        ▼
┌─ 导出文件 ────────────────────────────────────────────┐
│  Packages/cn.etetet.map/Bundles/ECA/{场景名}.txt      │
└───────────────────────────────────────────────────────┘
        │ 服务器启动时 ECALoader.LoadFromFile()
        ▼
┌─ 服务器运行时 ────────────────────────────────────────┐
│  ECAPointComponent (RangeTrigger, 200ms轮询玩家距离)  │
│    │ 玩家进入范围                                     │
│    ├─ 触发 OnPlayerEnterRange                         │
│    │   └─ ApplyStealth → SetPlayerConcealmentState    │
│    │ 玩家离开范围                                     │
│    ├─ 触发 OnPlayerLeaveRange                         │
│    │   └─ RemoveStealth → SetPlayerConcealmentState   │
│    ▼                                                  │
│  ExtraUnitVisibilityComponent                         │
│    ├─ 维护 concealmentSource ↔ player 双向映射        │
│    ├─ AOI 入视野时过滤隐身目标 (不发 CreateUnits)     │
│    └─ 广播消息时过滤隐身目标 (不转发给草丛外玩家)     │
└───────────────────────────────────────────────────────┘
        │ 客户端收到/未收到 CreateUnits
        ▼
┌─ 客户端运行时 ────────────────────────────────────────┐
│  ECAInteractClientComponent                           │
│    ├─ 从 ECA/{场景名}.txt 解析 ApplyStealth 节点      │
│    ├─ 构建 LocalConcealmentAreaData 列表              │
│    ├─ 每帧检测自身位置是否在草丛范围内                │
│    └─ 在范围内时设置自身角色 alpha = 0.5              │
└───────────────────────────────────────────────────────┘
```

## 3. 配置步骤

### 3.1 在 Unity 场景中放置草丛

1. 打开战斗场景（如 SDCMap）
2. 创建空 GameObject，移动到草丛位置
3. 添加 `ECAPointMarker` 组件
4. 填写字段：

| 字段 | 值 | 说明 |
|------|------|------|
| ConfigId | `eca_{地图名}_grass_{序号}` | 全局唯一，如 `eca_sdcmap_grass_001` |
| Type | `RangeTrigger` (5) | 下拉选择 |
| Params | `interact_range` = `3` | 草丛半径（米），按美术范围调整 |
| FlowGraph | 拖入 `GrassBushFlow.asset` | 路径: `Packages/cn.etetet.statesync/Assets/ECA/GrassBushFlow.asset` |

5.（可选）给 GameObject 添加子物体作为草丛视觉表现，材质可用 `Assets/GameRes/Materials/CaoCong.mat`（半透明绿色）

### 3.2 批量放置建议

- 每个草丛是一个独立的 ECAPointMarker GameObject
- ConfigId 必须唯一，建议用连续编号：`eca_sdcmap_grass_001` ~ `eca_sdcmap_grass_NNN`
- interact_range 可以不同，大草丛用更大半径
- 所有草丛共用同一个 `GrassBushFlow.asset`，不需要为每个草丛创建新的 FlowGraph

### 3.3 导出 ECA 配置

Unity 菜单栏：**ET → ECA → Export ECA Config**

导出结果：`Packages/cn.etetet.map/Bundles/ECA/{当前场景名}.txt`

导出后可搜索文件中的 `ApplyStealth` 关键字确认草丛点已包含在内。

### 3.4 启动验证

1. 启动服务器，观察日志搜索 `[ECALoader] Loaded ECA point: eca_sdcmap_grass`，确认草丛点已加载
2. 启动两个客户端，分别进入同一场景
3. 一个角色走进草丛 → 自身变半透明
4. 另一个角色在草丛外 → 看不到草丛内的角色
5. 两个角色都在同一草丛内 → 互相可见

## 4. GrassBushFlow.asset 结构

```
Event 1: OnPlayerEnterRange
  → Action 2: ApplyStealth
      Params: self_alpha = 0.5

Event 3: OnPlayerLeaveRange
  → Action 4: RemoveStealth
```

如果需要调整半透明程度，修改 Action 2 的 `self_alpha` 参数（0 = 完全透明，1 = 不透明）。

## 6. 常见问题

### Q: 草丛对怪物有效吗？

不影响。`ShouldConcealTargetFromViewer` 仅在双方都是 `UnitType.Player` 时生效。怪物的 AI 视野不受草丛影响。如需对怪物生效，需要额外扩展。

### Q: 草丛范围检测频率是多少？

默认 200ms 一次（`ECAConfig.DefaultCheckRangeIntervalMs`）。可以在 ECA 配置的 Params 中添加 `check_range_interval_ms` 自定义。

### Q: 玩家断线重连后遮蔽状态会丢失吗？

不会。`ExtraUnitVisibilityComponent` 在服务器 Map Scene 上持久存在。重连后玩家重新进入 AOI 范围时，`UnitEnterSightRange_NotifyClient` 会检查遮蔽状态，不会发送被遮蔽目标的 CreateUnits 消息。

### Q: 能否调整半透明度？

修改 `GrassBushFlow.asset` 中 ApplyStealth Action 的 `self_alpha` 参数。0.5 是当前默认值。

### Q: 如何新增烟雾弹等其他遮蔽源？

创建新的 FlowGraph Asset，在适当时机触发 ApplyStealth / RemoveStealth Action。`ExtraUnitVisibilityComponent` 支持多遮蔽源叠加——每个 sourceId 独立管理，玩家只要在任意一个遮蔽源中就处于隐身状态。
