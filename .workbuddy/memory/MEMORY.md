# MEMORY.md - 长期记忆

## 项目概要
- ET10 框架 Unity 游戏（代号"昭君"），模块化 Package 架构
- ECS 模式：Entity（数据）+ Component + System（逻辑）
- 双端 C#，支持热更新

## 用户偏好
- 全中文沟通（代码除外）
- 操作前先说明要做什么、为什么
- 文档驱动开发：无设计文档不写代码，无计划不开工
- 文档和代码必须同步，过一阵不知道哪个为准 → 建立三层文档体系解决

## 开发流程规范
1. **et-plan**：所有任务来自版本/周计划，状态流水线驱动
2. **et-design**：开发入口门禁，检查计划→检查设计文档→创建开发文档→开发→双更新
3. **et-tdd**：TDD 测试驱动
4. **et-arch**：ECS 架构规范检查
5. **et-build**：编译验证（唯一编译命令：dotnet build ET.sln）
6. **et-test-run**：测试执行

## 三层文档体系
- 宏观：版本/周计划 → `Book/08-版本计划/`
- 中观：设计文档 → `Book/{功能目录}/`
- 微观：开发文档（开发日志） → `Book/{功能目录}/`
