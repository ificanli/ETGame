# 项目模块化架构学习说明

更新时间：2026-03-02  
适用项目：`ETGame`（Unity + ET10）

## 1. 目的

这份文档用于建立“先理解架构，再改功能”的统一基线，重点支持你后续做枪械/英雄系统改造。

## 2. 总体架构（两层视角）

### 2.1 程序集分层（编译与运行层）

ET 体系建议按以下层次理解：

1. `ET.HotfixView`（客户端热更新视图层）
2. `ET.Hotfix`（客户端/服务端热更新逻辑层）
3. `ET.ModelView`（客户端视图模型层）
4. `ET.Model`（共享模型层）
5. `ET.Loader`（启动与加载）
6. `ET.Core`（核心基础）

学习建议：改业务逻辑优先看 `Model + Hotfix`；改 UI/表现优先看 `ModelView + HotfixView`。

### 2.2 Package 分层（模块依赖层）

包分层请以 `MyBook/说明文档/9.7包依赖结构说明.md` 为准。可快速记成：

1. 第0层：独立基础库（如 `sourcegenerator`, `memorypack`, `recast`）
2. 第1层：核心层（`core`, `proto`, `db`, `yooassets`）
3. 第2层：基础设施层（`unit`, `behaviortree`, `http`, `startconfig`, `console`）
4. 第3层：功能层（`numeric`, `move`, `netinner`, `router`, `item`, `equipment`）
5. 第4层：服务层（`actorlocation`, `aoi`）
6. 第5层：业务层（`statesync`, `map`, `login`, `spell`, `btnode`, `test`, `robot` 等）

## 3. 与“枪械/英雄”最相关的模块地图

### 3.1 局外起装链路

1. 英雄列表获取：`Packages/cn.etetet.equipment/Scripts/Hotfix/Server/C2G_GetHeroListHandler.cs`
2. 起装确认与校验：`Packages/cn.etetet.equipment/Scripts/Hotfix/Server/C2G_ConfirmLoadoutHandler.cs`
3. 起装数据存储：`Packages/cn.etetet.equipment/Scripts/Model/Server/LoadoutComponent.cs`
4. 客户端起装状态：`Packages/cn.etetet.equipment/Scripts/Model/Client/LoadoutComponent.cs`

### 3.2 进图与装备应用链路

1. 进图读取英雄并映射 Unit：`Packages/cn.etetet.map/Scripts/Hotfix/Server/C2G_EnterMapHandler.cs`
2. 起装应用到 Unit 装备槽：`Packages/cn.etetet.equipment/Scripts/Hotfix/Server/LoadoutHelper.cs`

### 3.3 局内武器战斗链路

1. 武器基础数据组件：`Packages/cn.etetet.statesync/Scripts/Model/Share/WeaponComponent.cs`
2. 武器逻辑（弹药/切枪/间隔）：`Packages/cn.etetet.statesync/Scripts/Hotfix/Share/WeaponComponentSystem.cs`
3. 行为树射击节点：`Packages/cn.etetet.statesync/Scripts/Hotfix/Server/BTNode/BTWeaponFireHandler.cs`
4. 子弹移动与命中：`Packages/cn.etetet.statesync/Scripts/Hotfix/Share/BulletComponentSystem.cs`

### 3.4 目标选择与锁定

1. 目标选择抽象根：`Packages/cn.etetet.spell/Scripts/Model/Share/TargetSelector.cs`
2. 选择器实现（位置/单体/圆形等）：`Packages/cn.etetet.btnode/Scripts/Hotfix/Server/Root`

### 3.5 动画与挂点表现

1. 动画组件系统：`Packages/cn.etetet.map/Scripts/HotfixView/Client/Unit/AnimatorComponentSystem.cs`
2. 挂点定义（含左右手）：`Packages/cn.etetet.map/Scripts/Model/Share/Map/Unit/BindPoint.cs`
3. 绑定点特效创建：`Packages/cn.etetet.map/Scripts/HotfixView/Client/EffectUnitHelper.cs`

## 4. 当前架构特征（用于改造时判断边界）

### 4.1 已打通的链路

1. 局外英雄/装备选择到进图生效主链路已存在。
2. 基础武器系统（双武器、弹药、射击间隔、简单切换）已存在。
3. 行为树 + 子弹命中链路可以形成最小战斗闭环。

### 4.2 仍需补齐的链路

1. 局内“2把枪按钮切换”的完整 UI-协议-服务端同步链路不完整。
2. 武器逻辑中存在硬编码（弹匣、射速、伤害），尚未配置化。
3. “移动可射 / 静止可射”未见按武器类型分型控制。
4. “位置锁定 / 方向锁定 / 强制目标锁定”未在武器系统形成统一分型。
5. 动画与武器模型挂接未形成“持枪/空手/切枪换模”的完整系统。

## 5. 修改时必须遵守的架构原则

1. Entity 只放数据，逻辑写到 System/Helper。
2. 有 `await` 的逻辑在 `await` 后必须通过 `EntityRef` 重新取实体。
3. 禁止 hardcode，优先用配置（Luban/Config）驱动。
4. 包依赖保持单向，新增依赖要补齐递归依赖。
5. 编译统一使用 `dotnet build ET.sln`。

## 6. 学习与改造建议顺序

1. 先读 `MyBook/说明文档/9.7包依赖结构说明.md`，建立包层级心智图。
2. 读起装链路代码（equipment + map），确认“局外到局内”数据路径。
3. 读 statesync 武器与子弹链路，明确当前战斗最小闭环。
4. 读 spell + btnode 目标选择器，确定锁定模式可复用点。
5. 读 map 动画与挂点代码，设计武器模型/空手动画切换方案。
6. 再按“现状报告与TODO”分阶段实施。
