# cn.etetet.map

## 概述

`cn.etetet.map` 负责地图场景、单位进出图、单位同步、地图消息与场景内基础交互。

## 开发约定

- 地图场景级组件优先挂在 `Scene` 上，单位级运行时状态优先挂在 `Unit` 上。
- 与客户端单位可见性、创建/移除直接相关的通用能力，优先放在本包内，避免高层玩法包反向侵入地图同步层。
- 地图层只提供通用同步与场景能力，具体玩法规则放到依赖本包的高层包实现。

## 依赖与边界

- 依赖以 `package.json` 为准，禁止直接引用未声明依赖包的玩法符号。
- 本包可以提供通用的地图广播、额外可见关系、传送与场景初始化能力，但不直接内置具体战术道具规则。
